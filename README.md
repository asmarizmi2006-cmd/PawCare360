# PawCare 360 - Veterinary Clinic Management

Java Swing enterprise app (NetBeans / Ant) with MySQL and JasperReports.
Modules: Login, Dashboard, Customers, Pet Patients, Staff, Services, Appointments,
Treatments (+ prescriptions), Grooming, Boarding, Billing (invoices + payments), Reports.

## 1. Database
1. Start MySQL (XAMPP).
2. Fresh install: run `database/pawcare360_full.sql`.
   Existing database: run `database/upgrade_billing_tables.sql` only (adds the new tables, safe to re-run).
3. Default connection: `jdbc:mysql://localhost:3306/pawcare360`, user `root`, empty password.
   Different settings: edit `db.properties` in the project root. The file contains the default XAMPP configuration.

## 2. Run
- NetBeans: open the project, Clean and Build, **run `LoginForm`** (not other forms - the logged-in role comes from login).
- Jar: `PawCare360.bat` or `java -jar dist/PawCare360.jar` (keep `dist/lib` beside the jar).
- Exe: run `build-exe.bat` (uses `jpackage`), result in `exe-output/PawCare360/PawCare360.exe`.

## 4. Reports (JasperReports)
Source `src/reports/*.jrxml`, compiled `*.jasper` (loaded at runtime, so no compiler is needed).
After editing a `.jrxml`, run `tools/compile-reports.bat`.
- Invoice (invoices, customers, pets, invoice_details, payments)
- Revenue & Collections + chart (invoices, customers, pets, payments)
- Service Performance + 2 charts (appointments, services, staff, customers, pets)

## 6. Structure (MVC + layers)
Every screen is a NetBeans designer form (`src/view/*.form`) - open it in the Design tab. Forms hold no logic; each has a controller in `src/controller`.
To change a layout generated by `tools/formspec/*.py`, edit it in the NetBeans designer (then the spec is no longer needed).
`view` (designer forms) -> `controller` (actions) -> `service` (rules, validation) -> `dao` (JDBC) -> `model`.
Support: `exception` (custom), `util` (Session, Validator, AccessControl, DBConnection).
See `docs/VIVA_GUIDE.md`.


## Keyboard & mouse events
All MVC forms use `util.UIHelper` so ENTER moves through editable fields consistently. Controllers also handle mouse table selection and button ActionListeners. See `docs/DB_AND_EVENTS_GUIDE.md`.
